# OctoAcme Project Management Docs

Welcome to the OctoAcme project management documentation. This folder is the single entry point for understanding how OctoAcme plans, executes, and continuously improves cross-functional projects.

## Overview

OctoAcme follows a lightweight, iterative project management workflow designed to deliver customer value through small, testable increments. Projects are owned by a named Project Manager (PM) and Product Manager (PdM), with clear roles for developers, QA, and stakeholders throughout the lifecycle.

The lifecycle covers five high-level stages: **Initiation → Planning → Execution → Release → Retrospective & Continuous Improvement**. Each stage has defined artifacts, responsibilities, and communication expectations to keep teams aligned and delivery on track.
